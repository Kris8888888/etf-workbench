# ETF 轮动记录台

一页式的 ETF 轮动 / 全天候 / 海龟策略回测台。打开 `index.html` 就能用，没有后端。

- `index.html` 页面本体。开页后先用仓库里的 `data.js`，再向腾讯行情补拉之后的交易日，补到的几天存在浏览器里，下次开页直接接上。
- `data.js` 21 只 ETF 从 2010 年起的每日含分红再投净值。腾讯给的复权价对分红是加减现金而非再投资，这里用不复权价加还原出的每次分红重算，逻辑见 `update.js` 开头的说明。
- `update.js` 增量更新模块，浏览器和 node 共用一份代码。`node update.js` 会把新交易日追加进 `data.js`。
- `.github/workflows/update.yml` 每个交易日北京时间 17:30 自动跑一次更新并提交。
- `_src/` 引擎抽取、回放校验等脚本；`_src/legacy/` 是改造前的单文件静态版。

回放校验：`node _src/test_update.js 200` 把最近 200 个交易日砍掉再重拉，逐日对比应全部一致。

**盘中信号（每天 14:30 用）**：页头「盘中信号」按钮会拉腾讯实时报价，把今天到此刻的涨跌接在净值末尾当临时的一天，立刻算出「今天该持有什么」，交易时段每分钟自动刷新。14:30 前后照它调仓，对应回测里的「当日收盘成交」口径（尾盘半小时的价差被忽略）。临时的一天不入库，17:00 后「重新拉取」拿到真正的收盘会替换掉它。

这是研究工具，不是投资建议。
